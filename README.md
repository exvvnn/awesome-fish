In the future I will create a helpful python function that will help add them to your path, and to your `config.fish` file. 

If you have questions please feel free to post them under Issues. Please do not troll my site. 
Thanks!

### Please note:
- The `.env-locals-copy` should be installed in the `.venv` folder that is generated by the install instructions; if an environment is not created please use `python3 -m venv .venv` and drag the env file into the venv folder. I will update the installables later to include this creation and modification in the coming versions. Thanks!
